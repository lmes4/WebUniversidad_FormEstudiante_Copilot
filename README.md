# Copilot3_Formularioestudiante
Sistema de Registro de Estudiantes - Universidad

Aplicación web estática y moderna para el registro y validación de datos de estudiantes universitarios, diseñada para el personal de registro académico.

📋 Descripción del Proyecto

Este proyecto implementa un formulario interactivo y una tabla de gestión en tiempo real. Permite capturar información de manera rápida, limpia y accesible con un diseño profesional enfocado en la experiencia de usuario (UI/UX).

🚀 Tecnologías
HTML5: Estructura semántica del sitio.
CSS3: Estilos personalizados, diseño adaptable (Responsive) y animaciones sutiles.
JavaScript (Vanilla): Lógica de validación, cálculo automático de edad y manipulación dinámica del DOM.

✨ Características y Criterios de Aceptación
Formulario en 2 columnas: Organizado visualmente para facilitar el llenado rápido.
Campos incluidos:
Identificación
Nombre y Apellido
Correo electrónico
País
Carrera (Ing. Informática, Ing. Electrónica, Ing. Telecomunicaciones, Ing. Robótica u Otra)
Fecha de nacimiento (con selector de fecha)
Edad (calculada de forma automática y en modo solo lectura)
Acciones: Botón de Registrar (primario) y botón de Limpiar (secundario).
Tabla de registros: Muestra en tiempo real la lista de estudiantes agregados.
Diseño visual: Paleta institucional en tonos azul, negro y gris con iconos integrados.
Animaciones profesionales: Transiciones fluidas en botones, alertas de éxito/error animadas y efecto de aparición (fade/slide) al insertar filas en la tabla.
